## Дефекты и перепроверки

### BUG-001 — API не предоставляет таблицы медицинского среза (BLOCKED)

В симуляторе главная показывает ошибку загрузки событий и предупреждение напоминаний. Read-only запросы `limit=0`, без пользовательских строк: `pets` → HTTP 200; `medical_events`, `reminders`, `storage_cleanup_outbox` → HTTP 404 / PGRST205. Причина отсутствия таблиц в schema cache (неприменённые миграции, экспонирование или доступ) требует проверки облачного проекта; фактическое наличие таблиц в PostgreSQL этим запросом не установлено.

Доказательства: `backend-readiness.json`, `bug-001-home-before.png`, `bug-001-home-return.png` в каталоге прогона. Облачная схема и RLS не изменялись. Миграции медицинского среза уже есть в репозитории: `20261002120000_stage_two_medical_history.sql` и `20261003120000_stage_two_hardening.sql`; перед применением нужна проверка текущей migration history и состояния облачной базы. Автоматически применять их в рамках этого прогона запрещено.

Статический аудит не считается воспроизведением других дефектов.
