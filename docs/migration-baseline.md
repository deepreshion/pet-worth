# Исходная точка миграции React Native

Дата: 1 ноября 2026. База — рабочее дерево, включая незакоммиченные изменения.
Резервная копия до изменений: `/private/tmp/pet-worth-before-expo/source.tar.gz`; diff и статус находятся рядом. Копия не содержит `.env`, node_modules и Git.

Проверки до миграции: 20 файлов / 105 тестов, TypeScript, ESLint, production build прошли. Сборка предупреждает о крупном чанке. Проверки устройств не проводились.

| Область     | Сохраняемое поведение                                                                   |
| ----------- | --------------------------------------------------------------------------------------- |
| Вход        | Email magic link, PKCE callback, восстановление сессии, выход                           |
| Питомцы     | Несколько питомцев, выбор, создание, редактирование, фото, приблизительный возраст, вес |
| История     | Четыре типа, создание по шагам, редактирование, удаление с подтверждением, фильтр       |
| Главная     | Выбор питомца, календарь всех событий, выбранный день, ближайшие события                |
| Документы   | Фото/PDF до 20 МБ, просмотр, скачивание, системная отправка, частичные ошибки           |
| Напоминания | Локальные за 24 часа, timezone события, отмена, переход в событие                       |
| Настройки   | Имя, timezone, ru/en, system/light/dark                                                 |
| Состояния   | Загрузка, пусто, ошибка/повтор, несохранённые изменения, защита от двойного сохранения  |

Удаляются по согласованию: Web, Pages, demo. Не добавляются: лекарства, приглашения, remote push, offline editing.
Серверная схема и RLS остаются без изменений. Повторный вход допустим, старые локальные настройки не мигрируются.
