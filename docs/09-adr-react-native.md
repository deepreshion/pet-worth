# ADR-002: React Native и Expo

Статус: принято пользователем 1 ноября 2026. Заменяет ADR-001 в части клиентского стека. Реализация и приёмка отслеживаются отдельно в migration-verification.md.

Клиент переносится на Expo SDK 58 / React Native 0.88 / React 19.3: development builds, Expo Router native stack/native tabs, TanStack React Query, React Hook Form, Zod 4 и TypeScript. Прямые зависимости закреплены, lockfile хранится в Git. iOS 16.4+, Android 7+.

Supabase, RPC, RLS и приватные buckets сохраняются. Клиент не содержит service_role. Сессия и настройки хранятся через AsyncStorage. CNG/Prebuild генерирует нативные проекты из конфигурации; локальные сборки не зависят от EAS. OTA не подключается.

UI сохраняет палитру и продуктовые сценарии текущего рабочего дерева, но использует нативные элементы, клавиатуру и навигацию. Web, Pages и demo удаляются. Разрешён повторный вход после обновления; локальные данные Capacitor не мигрируются.

Полная приёмка требует сборок обеих платформ и проверки сценариев на устройствах. Успешный export бандлов или unit-тесты не заменяют эти проверки. Лекарства, приглашения, remote push и offline editing не входят в миграцию.
