- Последняя запись: анализ крови с прикреплёнными результатами

## Зафиксированный прототип

Основной прототип страницы питомца строится вокруг крупной пользовательской фотографии и плавающей белой карточки. В интерфейсе используются яркий голубой фон, чёрная типографика, лаймовый активный пункт навигации, сиреневые вторичные карточки и коралловый акцент события.

На первом экране остаются только основные действия, вес, текущее лекарство и ближайшее событие. Статус питомца, признак «домашний» и отдельные кнопки редактирования не показываются.

На главной нет отдельной кнопки «Сменить питомца». Если в семье больше одного питомца, карточки образуют горизонтальную карусель и переключаются свайпом с фиксацией на ближайшей карточке. Для одного питомца горизонтальная прокрутка отключена.

Рукописная заметка поверх фотографии пока не показывается. Она остаётся идеей для будущей функции заметок о питомце и не входит в текущий интерфейс.
