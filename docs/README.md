# Pet Worth — проектная документация

Статус: черновик для согласования, версия 0.1.

Рабочее название продукта — **Pet Worth**. Образ чёрного кота Сени служит источником визуальных отсылок в логотипе и фирменном стиле, но не выделяется в отдельный раздел приложения.

## Документы

1. [Концепция продукта](./01-product-concept.md) — ценность, аудитория, границы MVP и правила продукта.
2. [Пользовательские потоки](./02-user-flows.md) — основные сценарии и диаграммы.
3. [Модель данных и архитектура](./03-data-and-architecture.md) — сущности, связи и технические варианты.
4. [План реализации](./04-delivery-plan.md) — этапы, результаты, критерии готовности и вопросы для согласования.
5. [Семья и совместный доступ](./05-family-sharing.md) — роли, приглашения, совместные действия и пограничные сценарии.
6. [ADR-001: технический стек MVP](./06-adr-technical-stack.md) — зафиксированный выбор Ionic Vue, Capacitor и Supabase, границы решения и условия пересмотра.
7. [Дизайн-кит](./07-design-kit.md) - концепция, цвет, типографика, компоненты и правила визуальной системы.

## Порядок согласования

Документы предлагается утверждать последовательно:

1. Ценность продукта и состав MVP.
2. Пользовательские сценарии.
3. Данные и правила доступа.
4. Техническая архитектура и этапы разработки.
5. Визуальная концепция и прототип экранов.

После каждого согласованного блока его статус меняется с `Черновик` на `Утверждено`. Существенные изменения фиксируются отдельной записью решения.
