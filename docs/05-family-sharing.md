# Семья и совместный доступ

Статус: **Бизнес-логика первой версии согласована**

Версия: **0.2**

Дата согласования: **6 ноября 2026 года**

Документ фиксирует согласованное поведение продукта. Он не означает, что описанные функции уже реализованы. Для первой версии семейного доступа эти правила заменяют прежний черновик с тремя ролями и совместным редактированием.

## 1. Семьи и питомцы

- При регистрации пользователь получает одну собственную семью и становится её владельцем.
- У пользователя может быть только одна собственная семья. Все добавляемые им питомцы автоматически попадают в неё, выбирать семью при создании питомца не требуется.
- Один питомец принадлежит только одной семье.
- Пользователь может одновременно состоять участником в других семьях. Присоединение не удаляет и не заменяет его собственную семью, питомцев и историю.
- Все участники видят всех питомцев семьи и связанные с ними данные.
- Если доступна одна семья, табы семей не нужны. Если семей больше одной, список питомцев разделяется табами по семьям.
- После присоединения открывается таб новой семьи с её питомцами.

## 2. Название семьи

- Начальное название собственной семьи — «Моя семья».
- Владелец может изменить название своей семьи.
- Название используется в табах и на экране приглашения.
- Для приглашённой семьи с названием по умолчанию отображается «Семья Анны» — по имени владельца. Если владелец задал своё название, отображается оно.

## 3. Права владельца и участника

В первой версии есть два уровня доступа. При создании приглашения роль не выбирается: приглашённый получает доступ участника только для просмотра.

| Действие | Владелец | Участник |
|---|:---:|:---:|
| Просматривать всех питомцев семьи | Да | Да |
| Просматривать медицинскую историю и напоминания | Да | Да |
| Просматривать и скачивать документы | Да | Да |
| Получать push-уведомления о напоминаниях семьи | Да | Да |
| Добавлять, редактировать и удалять питомцев | Да | Нет |
| Добавлять, редактировать и удалять медицинские записи | Да | Нет |
| Загружать и удалять документы | Да | Нет |
| Создавать и изменять напоминания, отмечать выполнение | Да | Нет |
| Переименовывать семью | Да | Нет |
| Создавать приглашения | Да | Нет |
| Просматривать список участников семьи | Да | Нет |
| Исключать участников | Да | Нет |
| Выходить из семьи, к которой присоединился | — | Да |

Права определяются отдельно для каждой семьи: в собственной семье пользователь — владелец, в чужой — участник. Изменения данных выполняет только владелец; участник получает доступ для просмотра и скачивания документов.

## 4. Создание приглашения и отправка

1. Владелец открывает раздел «Семья» и нажимает «Пригласить».
2. Приложение сразу создаёт отдельное приглашение и показывает QR-код. Ввод имени, email или телефона получателя не требуется.
3. В QR закодирована ссылка на это приглашение.
4. Получатель может отсканировать QR с экрана владельца.
5. По кнопке «Поделиться» открывается системное меню отправки: передаются картинка с QR и кликабельная ссылка на то же приглашение.

### Правила действия

- Каждое приглашение одноразовое и действует **24 часа с момента создания**. Отправка или просмотр не продлевают срок.
- У владельца может быть несколько действующих приглашений одновременно: отдельное приглашение и QR для каждого человека.
- Копии картинки и ссылки относятся к одному приглашению и не создают дополнительных приглашений.
- Приглашение не привязано к заранее указанному получателю: присоединиться может человек, которому его передали.
- Отзыв приглашения владельцем в первую версию не входит.
- Приглашение становится недействительным после успешного присоединения, истечения срока или открытия уже состоящим в семье участником. Для владельца действует исключение, описанное ниже.

## 5. Открытие и принятие приглашения

1. Человек сканирует QR или открывает ссылку.
2. Если приложение не установлено, открывается страница с переходом в магазин приложений. Автоматическое восстановление приглашения после установки и дополнительный сценарий продолжения в первую версию не входят.
3. Если человек не авторизован, сначала предлагается войти или зарегистрироваться. Контекст приглашения сохраняется на время авторизации.
4. После авторизации проверяются приглашение и членство пользователя в семье.
5. Для действующего приглашения новому пользователю показываются название семьи, имя владельца и кнопка «Присоединиться».
6. Просмотр этого экрана новым пользователем не расходует приглашение.
7. По нажатию «Присоединиться» человек сразу становится участником. Дополнительного подтверждения владельца не требуется.
8. Приглашение становится недействительным, владельцу отправляется push о присоединении, например: «Анна присоединилась к вашей семье».
9. Новому участнику открывается таб этой семьи с её питомцами. Собственная семья сохраняется.

Пока человек не присоединился, приглашение не даёт доступа к питомцам, медицинской истории и документам семьи.

### Повторное открытие и особые случаи

| Ситуация | Результат |
|---|---|
| Действующее приглашение открывает человек, ещё не состоящий в семье | Экран приглашения с кнопкой «Присоединиться»; просмотр не расходует приглашение |
| Действующее приглашение открывает уже состоящий в семье участник | Сообщение «Вы уже в этой семье»; приглашение становится недействительным, даже без нажатия «Присоединиться» |
| Собственное действующее приглашение открывает владелец | Приглашение остаётся действующим; владелец не присоединяется повторно |
| Приглашение просрочено или уже стало недействительным | «Приглашение недействительно. Попросите владельца отправить новое» |
| Несколько человек одновременно пытаются принять одно приглашение | Присоединиться может только один; остальные получают сообщение о недействительном приглашении |

Одно приглашение не может создать несколько членств. Один пользователь не может состоять в одной семье дважды. Создание членства и погашение приглашения должны завершаться как единое действие: неуспешное присоединение не считается успешным использованием приглашения.

## 6. Напоминания и документы

- Участники получают push-уведомления о напоминаниях семьи, несмотря на доступ только для просмотра.
- Создаёт и изменяет напоминания, а также отмечает выполнение только владелец.
- Участник может просматривать документы внутри приложения и скачивать их на устройство.
- Загружать, изменять и удалять документы может только владелец.

## 7. Выход и исключение

### Выход участника

1. Участник выбирает «Выйти из семьи».
2. Приложение запрашивает подтверждение.
3. После подтверждения членство прекращается, доступ к семье закрывается, все push-уведомления этой семьи для человека прекращаются.
4. Питомцы, документы и история остаются в семье. Собственная семья вышедшего пользователя сохраняется.

### Исключение владельцем

1. Владелец открывает список участников и выбирает человека для исключения.
2. Приложение запрашивает подтверждение.
3. После подтверждения участник сразу теряет доступ к семье и перестаёт получать все её push-уведомления.
4. Питомцы, документы и история семьи сохраняются.

После выхода или исключения человек может снова присоединиться по новому приглашению. Эти правила относятся к доступу к семье в приложении: уже скачанные на устройство документы остаются у пользователя.

## 8. Границы первой версии

В согласованный процесс не входят:

- выбор роли или отдельных разрешений при приглашении;
- редактирование данных приглашёнными участниками;
- выборочный доступ к отдельным питомцам;
- ввод контактов получателя при создании приглашения;
- отзыв приглашения;
- показ списка членов семьи обычным участникам;
- автоматическое продолжение приглашения после установки приложения из магазина.

Передача владения, выход владельца из собственной семьи, удаление семьи и перенос питомцев между семьями этим согласованием не определены и требуют отдельного решения. Назначение ответственных за напоминания, подробный журнал активности и дополнительные категории семейных уведомлений не являются требованиями этого процесса.

## 9. Критерии приёмки

- Владелец получает QR без ввода контактов и может поделиться картинкой вместе со ссылкой.
- Несколько созданных приглашений действуют независимо, каждое не более 24 часов.
- Неавторизованный получатель сначала входит или регистрируется, затем возвращается к приглашению.
- Без подтверждения «Присоединиться» новый пользователь не получает доступ и не расходует приглашение.
- Успешное принятие даёт доступ только одному человеку, открывает таб новой семьи и вызывает push владельцу.
- Собственная семья и питомцы присоединившегося пользователя сохраняются.
- Открытие владельцем не расходует действующее приглашение; открытие существующим участником расходует его с сообщением «Вы уже в этой семье».
- Участник просматривает данные и скачивает документы, но не может изменять данные семьи.
- Выход и исключение требуют подтверждения, закрывают доступ и прекращают все push этой семьи для человека.
- После выхода или исключения можно вернуться по новому приглашению.
