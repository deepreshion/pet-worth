# Pet Worth — запуск и разработка

Мобильное приложение iOS/Android на React Native и Expo: профили питомцев, медицинская история с фото/PDF, календарь и локальные напоминания. Supabase Auth, PostgreSQL и приватные buckets остаются серверной частью. Web, деморежим и GitHub Pages удалены.

## Запуск

Node.js 22.13+, npm, Xcode 26.4+ и CocoaPods для iOS; JDK 17, Android SDK/Android Studio для Android. Поддерживаются iOS 16.4+ и Android 7+. Для локального сервера нужны Docker и Supabase CLI.

```sh
npm ci
cp .env.example .env
npm run supabase:start
```

В `.env` задать `EXPO_PUBLIC_SUPABASE_URL` и `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` из локального Supabase. Для iOS Simulator URL — `http://127.0.0.1:54321`; для Android Emulator — `http://10.0.2.2:54321`. Для физического телефона нужен доступный с него адрес тестового сервера. Secret/service-role ключи в клиенте запрещены.

```sh
npm run ios
# или
npm run android
```

Команды генерируют нативный проект и запускают development build. Для следующих запусков Metro: `npm run dev`. Используется development client, Expo Go не является средой приёмки. EAS, Expo-аккаунт и OTA не нужны.

Если Xcode установлен, но не выбран, выполнить команду с `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`. Нативные каталоги генерируются и не хранятся в Git. Изменять настройки следует в `app.config.ts` или config plugins. Отдельная генерация без установки системных зависимостей: `npm run native:generate`.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run supabase:test
```

`build` экспортирует JS/Hermes-бандлы обеих платформ; это не APK и не iOS-приложение. CI отдельно собирает Android debug APK и iOS Simulator target. Инструкции E2E: [e2e/README.md](../e2e/README.md). Статус проверки: [docs/migration-verification.md](./migration-verification.md).

## Авторизация, файлы и уведомления

Идентификатор приложения — `app.petworth.mobile`, redirect URL — `petworth://auth/callback`; добавить его в Supabase Auth URL Configuration. Новый вход использует 6-значный код из письма; обработчик старых PKCE-ссылок сохранён. Resend SMTP пока настроен для тестовой отправки только владельцу аккаунта Resend — [настройки и ограничения OTP](./auth-otp.md). Сессия хранится через AsyncStorage, токен обновляется при активном приложении. После миграции со старого клиента разрешён повторный вход. Серверные данные сохраняются; локальные настройки и демо-данные не переносятся.

Файлы закрыты по умолчанию. Ссылки для просмотра создаются заново и действуют 60 секунд. Фото открываются внутри приложения, PDF — в системном браузере. Скачанные документы находятся в Documents/Pet Worth и доступны для экспорта через Share; выход удаляет локальную копию приложения. Экспортированные пользователем копии остаются у него.

Локальные уведомления планируются за 24 часа в часовом поясе события. Разрешения запрашиваются при включении; Android дополнительно требует разрешения точных будильников. iOS ограничивает очередь 64 запросами: приоритет у ближайших событий. Очередь сверяется при запуске, возобновлении, изменении событий и языка. Ошибки показываются в интерфейсе. Изменение на другом устройстве не обновляет закрытое приложение: серверные push и offline-синхронизация не входят в текущую версию.

Опционально `EXPO_PUBLIC_SENTRY_DSN` включает технический crash reporting с удалением пользовательских данных. Медицинские сведения, тексты ошибок сервера и токены не должны попадать в отчёты.
