# E2E первого этапа

`stage-one-demo.yaml` воспроизводимо проверяет основной CRUD-сценарий без ручного перехода по email: development-only деморежим создаёт второго питомца, редактирует его и проверяет восстановление после перезапуска приложения.

Запуск:

```bash
npm run build
npm run cap:sync
npm run e2e:smoke
```

Для отдельной проверки magic link используется локальный Supabase и Inbucket (`http://127.0.0.1:54324`). Запустите `npm run supabase:start`, войдите с тестовым адресом, откройте письмо в Inbucket и используйте callback. Этот шаг остаётся интеграционной проверкой окружения, потому что Maestro не должен получать или сохранять auth token в сценарии.
